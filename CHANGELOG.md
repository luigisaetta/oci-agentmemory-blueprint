# Changelog

All notable changes to this project are documented in this file.

## Unreleased

### Added

* Added Example 03, which authenticates OCI Generative AI model calls through
  an OCI Resource Principal while persisting Agent Memory in ADB.
* Added Resource Principal configuration helpers, documentation, specification,
  and unit tests, including OCI Data Science Notebook Session guidance.
* Reworked the Example 02 documentation around generating a compact Context
  Card from a stored conversation and preparing it for a subsequent LLM turn.
* Added Example 02, which persists a ten-message English customer-support
  conversation in an Oracle Agent Memory thread backed by Oracle ADB.
* Added specification, documentation, and unit tests for the Example 02
  conversation persistence behaviour.

### Changed

* Moved the Example 02 customer-support message construction into a dedicated
  local module to improve the readability of its persistence flow.
* Made the Oracle Agent Memory connection example safe to import and improved
  its local configuration validation and shutdown behaviour.
* Simplified the example startup flow by creating the ADB connection pool
  directly with `oracledb.create_pool`.
* Moved shared ADB and OCI configuration helpers into `common.py` for reuse by
  future examples.
* Simplified Example 01 validation errors to report invalid configuration or
  thread-message input safely.
* Display the thread ID generated by Oracle Agent Memory for every Example 01
  run.
* Timestamp Example 01 sample messages at insertion time in UTC.
* Use synchronous thread-message insertion in Example 01 while retaining
  background memory extraction for derived memories.
* Log complete local stack traces when Example 01 startup fails.
* Document Example 01 execution, internal logging, and the latency and
  consistency trade-offs of background memory extraction.
* Clarified that Example 01 demonstrates client creation, thread creation, and
  message insertion in addition to background memory extraction.
